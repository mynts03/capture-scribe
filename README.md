# CaptureScribe

CaptureScribeは、Macの画面を録画し、保存した動画をローカルで分割・文字起こしする開発途中のデスクトップアプリです。今回の公開はソースコードが対象です。

## できること

- ディスプレイ全体または指定範囲を録画し、MP4として保存できます。システム音声とマイクは個別に設定できます。
- 録画履歴から動画を選ぶと、末尾無音の短縮、動画分割、文字起こしを個別に選択して実行できます。結果は別ファイルに保存され、元の録画は保持されます。
- 日本語・英語のUIを切り替えられます。文字起こしにはmacOS標準のApple Speechを使用し、結果をテキストで保存します。

## 録画と管理ファイルの保存場所

新規録画のMP4、分割動画、文字起こしTXTは指定した保存先に並びます。同じ保存先の隠しフォルダ `.capturescribe` に、履歴と処理に必要な管理ファイルを保存します。

旧版が保存先直下に作成した管理ファイルは、現在の場所で引き続き使用します。両方の配置を履歴で読み取れます。競合する管理情報がある場合は対象を無効にし、安全に特定できるまで処理を受け付けません。

`.capturescribe` と旧版の管理ファイルは録画と一緒に保全してください。管理フォルダだけを移動・削除したり、別の動画を同名で置いたりすると、履歴や再処理で利用できなくなります。保存場所の変更や別のボリュームへのコピー後の自動照合は行いません。保存先にはハードリンクを作成できるファイルシステムが必要です。再マウント後にファイルシステムの識別子が変わると、新規配置の録画を利用できない場合があります。

## 確認した環境と依存関係

ソースからのローカルビルドは、Apple Silicon（arm64）のmacOS 26.6.2、Xcode 27.2（macOS SDK 27.2、Swift 6.4.2）、Rust/Cargo 1.96.0、Node.js 24.16.0、npm 11.13.0で確認しました。

アプリと録画ヘルパーのターゲットはmacOS 15以降です。文字起こしにはmacOS 26以降と、Apple Speechが利用できる環境・対象言語モデルが必要です。macOS 15での全機能、Intel Mac、Windowsの動作は未検証です。

末尾無音の短縮、分割、文字起こしにはPython 3と、別途用意したFFmpeg・ffprobeが必要です。録画ファイルの保存確認にもffprobeを使うため、アプリを起動する環境の `PATH` から見つかるようにしてください。既存の録画・分割・文字起こし確認にはApple SiliconのMacとFFmpeg／ffprobe 8.1.2を使用しました。一部の分割箇所を再エンコードする機能は `libx264` が有効なFFmpegを使います。

## ビルドと起動

フル版のXcodeとarm64用のRustツールチェーンを用意し、プロジェクトのルートで実行します。依存関係はnpmとCargoのロックファイルに従って取得します。

```sh
npm ci
cargo fetch --locked --target aarch64-apple-darwin --manifest-path src-tauri/Cargo.toml
npm run tauri -- build --bundles app --no-sign --ci -- --locked
```

アプリは通常 `src-tauri/target/release/bundle/macos/` に生成されます。同じシェルで `command -v ffprobe` を実行し、見つかることを確認してから起動してください。

```sh
"src-tauri/target/release/bundle/macos/CaptureScribe.app/Contents/MacOS/capture-scribe-studio"
```

macOSから求められた場合は、使う機能に応じて画面・システム音声収録やマイクの権限を設定してください。この手順で生成するのはローカル確認用のビルドです。一般配布用の署名・公証は別途必要です。

## CLI操作

コマンドラインから、録画状態の確認や次回の録画範囲の一時指定などを行えます。アプリバンドル内の相対位置は `Contents/MacOS/capture-scribe-control` です。上の手順でビルドした場合は、プロジェクトのルートから次のコマンドで使い方を確認できます。

```sh
"src-tauri/target/release/bundle/macos/CaptureScribe.app/Contents/MacOS/capture-scribe-control" --help
```

ヘルプの表示にはアプリの起動も接続も不要です。外部制御は通常の起動時には無効で、実際の操作には利用者の許可と認証が必要です。録画の開始・停止、分割、文字起こしはアプリ画面から行います。

## 既知の制限

- 分割は指定した間隔に近い位置で行います。素材のキーフレーム配置やFFmpegの構成によって、境界がずれたり、分割結果が得られず警告が出たりする場合があります。現行のMac開発版では、約35分の録画が5分設定で7本に分割されることを確認しました。
- 末尾無音の短縮は新規設定でOFFです。ONの場合、音声が静かな末尾は画面が動いていても短縮候補になります。安全検査で処理が中断した場合は、元の録画から再確認できます。プレーヤーによっては終端付近のシーク時の表示が異なります。
- 文字起こしの精度は素材・言語モデル・音声条件に左右されます。前回のMac検証で日本語と英語の文字起こしを確認しました。歌唱などでは実用に足りない結果になることがあります。
